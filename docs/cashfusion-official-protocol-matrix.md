# CashFusion Official Protocol Matrix

This matrix tracks OpalFusion's current native Swift implementation against the official Electron Cash CashFusion baseline. The normative target is Electron Cash `4.4.3`, matching the baseline already pinned in `cashfusion-implementation-spec.md`.

Normative references:

- Electron Cash `4.4.3` release: <https://github.com/Electron-Cash/Electron-Cash/releases/tag/4.4.3>
- Official schema: <https://raw.githubusercontent.com/Electron-Cash/Electron-Cash/4.4.3/electroncash_plugins/fusion/protobuf/fusion.proto>
- Official protocol constants: <https://raw.githubusercontent.com/Electron-Cash/Electron-Cash/4.4.3/electroncash_plugins/fusion/protocol.py>
- Primary framing reference: <https://raw.githubusercontent.com/Electron-Cash/Electron-Cash/4.4.3/electroncash_plugins/fusion/connection.py>

Public support context: [`cashfusion-native-support-statement.md`](cashfusion-native-support-statement.md) summarizes the current native Swift support claim and remaining proof gates without changing the row-level status values below.

Status values:

- `Supported`: Current native Swift implementation and tests cover the official requirement for the targeted client behavior.
- `Partial`: Current implementation supports the main path, but coverage or enforcement is incomplete.
- `Gap`: Current implementation does not yet support the official requirement.
- `Intentional exclusion`: The item is official, but is deliberately outside OpalFusion's client package boundary.
